# 推奨空気圧 計算式の検証表

アプリの推奨空気圧（現行式）と、メーカーの公開データとの差を記録する表です。
比較データが十分に集まった段階で、係数の最適化を再検討します（それまでは係数を変更しません）。

## 現行式（2026-10-30 時点・変更なし）

```
空気圧(PSI) = 337 × 荷重(kg)^0.9 ÷ タイヤ幅(mm)^1.5
前輪荷重 = 合計重量 × 0.48、後輪荷重 = 合計重量 × 0.52
```

係数 337・荷重指数 0.9・幅指数 1.5 は、作成時に実測データで裏付けたものではありません。

|---|---|---|
| Schwalbe Pro One TLE | ✅ 取得済み（2026-10-30） | 公開推奨値の表。リム内幅19mm。**このタイヤ専用の比較用データ**であり、全タイヤの基準値とはしない |
| SILCA Pro Tire Pressure Calculator | ❌ 未取得 | 計算ページ形式で数値表が公開されていない。実際の出力値を取得するまで「一致している」とは説明しない |
| SRAM / Zipp Tire Pressure Calculator | ❌ 未取得 | 同上。入力項目（車種・路面・重量・幅・ケーシング・リム構造・リム内幅）のみ確認済み |

## 比較1：Schwalbe Pro One TLE（リム内幅19mm、ドライ）

比較の条件：
- Schwalbe の表は体重帯ごとの値のため、現行式は **体重帯の中央値＋車体9kg** で計算
- Schwalbe の表の体重に車体が含まれるかは明記されていない（車体を含まないものとして比較）
- Schwalbe の表はチューブレス／チューブを区別していないため、現行式はチューブレス（補正なし）で比較
- 差 = 現行式 ÷ Schwalbe − 1

### 結果のまとめ

- 18条件・前後36値のすべてで、現行式は Schwalbe より低い
- 差の平均 **−11.6%**、範囲 −6.8%〜−18.2%
- 体重が重いほど差が広がる傾向（81-85kg 帯で −14〜−18%）
- 一般に、メーカーの推奨値は SILCA・SRAM などの計算ツールより高めと言われるが、本表では未確認

## 安全チェック用の参考データ（未実装・検討中）

フックレスリム（TSS）での Schwalbe 推奨上限（TLE/TLR タイヤ）：

| タイヤ幅 | 上限 |
|---|---|
| 18〜24mm | 5.5 bar / 80 PSI |
| 25〜29mm | 5.0 bar / 72 PSI |
| 30〜34mm | 4.5 bar / 65 PSI |

- リムメーカーの上限がタイヤより低い場合は、リムの上限を守る（Schwalbe）
- フックレスリムには TLE/TLR（チューブレス対応）タイヤのみ使用可。チューブを入れる場合も同じ（Schwalbe）
- Zipp のフックレスリムは全モデル 72.5 PSI / 5 bar が上限（Zipp サポート）
- ETRTO の一般的な上限は 5 bar（72.5 PSI）
