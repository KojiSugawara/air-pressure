# 自転車 空気圧 単位変換

自転車タイヤの空気圧を PSI / bar / kPa / kgf/cm² で相互に変換し、ロードバイクの推奨空気圧の目安も出せる Web アプリ（PWA）です。

https://kojisugawara.github.io/air-pressure/

## インストール

- **iPhone**：Safari で上の URL を開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chrome で上の URL を開き、右上の「︙」→「アプリをインストール」（または「ホーム画面に追加」）

一度開けば、電波がなくても使えます。

## 機能

### 1. 単位変換

- 「入力する単位」と「変換後の単位」を大きいボタンで選ぶ（PSI / bar / kPa / kgf/cm²）
- 最初は **PSI → kgf/cm²** の状態で開く
- 同じ単位を両方で選ぶと、もう一方と自動で入れ替わる
- 「⇅ 入れ替え」ボタン：入力と変換後の単位を入れ替え、結果の値を入力欄に移す
- 入力すると即座に結果を表示。残り2つの単位での値も下に表示
- 全角数字・カンマ入りでも入力可。0以上の数字以外はエラー表示

表示桁数：PSI 小数1桁、bar 小数2桁、kPa 整数、kgf/cm² 小数2桁

換算係数（1単位あたりの kPa）：

| 単位 | kPa |
|---|---|
| PSI | 6.894757 |
| bar | 100 |
| kPa | 1 |
| kgf/cm² | 98.0665 |

### 2. 前輪・後輪の空気圧の保存

- 「今の値を前輪に」「今の値を後輪に」で、変換中の値を保存
- 保存した値は PSI を大きく、左下に bar、右下に kgf/cm² を小さく表示（推奨空気圧の目安の前輪・後輪欄も同じ表示）
- 保存値がない間は「未保存」と表示（推奨欄は、体重が未入力の間は空欄）
- 保存した値をタップすると、変換欄に呼び出す（今選んでいる入力単位に換算して入る）
- 推奨空気圧の目安からも保存できる

### 3. 推奨空気圧の目安（ロードバイク）

入力項目：

| 項目 | 選択肢・範囲 | 初期値 |
|---|---|---|
| 体重 | 30〜150 kg | 空欄 |
| 車体＋装備の重さ | 5〜25 kg | 9 kg |
| タイヤ幅 | 25 / 28 / 30 / 32 mm | 28 mm |
| 路面 | ドライ / ウエット | ドライ |
| タイヤの種類 | チューブレス（レディ） / クリンチャー（ボタンは「チューブレス」「（レディ）」の2段表示） | チューブレス（レディ） |

計算式（結果は PSI。表示は PSI・bar・kgf/cm²）：

```
合計重量 = 体重 + 車体＋装備
前輪荷重 = 合計重量 × 0.48
後輪荷重 = 合計重量 × 0.52

空気圧(PSI) = 337 × 荷重(kg)^0.9 ÷ タイヤ幅(mm)^1.5
  ウエット      → × 0.93（約7%下げてグリップ重視）
  クリンチャー  → × 1.06（約6%上げてリム打ちパンクを防ぐ）
```

- タイヤのつぶれ量を一定に保つ考え方をもとにした経験式。係数は作成時に私（Claude）の知識で一般的な目安に合わせたもので、実測データや SILCA・SRAM の実際の出力値では確認していない。メーカー公式の値でもない
- Schwalbe Pro One TLE の公開推奨値と比べると平均約12%低い（詳細は [検証表](docs/verification.md)）

計算式の方針（2026-10-30 決定）：
- 係数 337・荷重指数 0.9・幅指数 1.5 は、比較データが十分に集まるまで変更しない
- Schwalbe の公開値は比較用データとし、全タイヤの基準値とはしない
- SILCA・SRAM/Zipp は、実際の出力値を取得するまで「一致している」と説明しない
- リム内幅・タイヤ実測幅の入力は今後の検討項目（[検証表](docs/verification.md)に参考データ）
- 後輪が 72.5 PSI（5.0 bar）を超えると、フックレスリムの上限についての注意を表示
- 「この目安を前輪・後輪に保存」で、前輪・後輪の保存欄に入れる

計算例（体重65kg・車体9kg・28mm・ドライ）：

| タイヤの種類 | 前輪 | 後輪 |
|---|---|---|
| チューブレス（レディ） | 3.97 kgf/cm²（56.5 PSI） | 4.27 kgf/cm²（60.8 PSI） |
| クリンチャー | 4.21 kgf/cm²（59.9 PSI） | 4.53 kgf/cm²（64.4 PSI） |

### 4. 安全チェック（詳細設定）

推奨空気圧の数値・計算式は一切変えず、上限を超えていないかの **警告だけ** を出す機能。「詳細設定（安全チェック）」を開いて入力する（何か入力済みなら最初から開いた状態）。

入力項目：

| 項目 | 選択肢 | 初期値 |
|---|---|---|
| リム構造 | フック付き / フックレス / 不明 | 不明 |
| 最大空気圧の単位 | bar / PSI / kgf/cm² | bar |
| リム最大空気圧 | 任意（1〜15 bar 相当の範囲） | 未入力 |
| タイヤ最大空気圧 | 任意（同上） | 未入力 |

判定ルール（前輪・後輪を個別に判定し、個別に表示）：

- 上限の候補：リム最大空気圧、タイヤ最大空気圧、フックレスなら一般的な上限の目安 5.0 bar
- 候補の中で **いちばん低い値** を上限とする（メーカー指定が 5.0 bar より低ければそちらが優先される）
- 30〜32mm でも一律 4.5 bar にはしない（フックレスは幅によらず 5.0 bar を目安とし、それより低い上限はメーカー指定の入力で判定）
- 範囲外の値・数字以外の入力はチェックに使わず、入力欄の下にエラーを表示

| 表示 | 条件 |
|---|---|
| ⚠ 上限超過 | 推奨値がわかっている上限を超えている |
| 安全性未確認 | リム構造・リム最大空気圧・タイヤ最大空気圧のどれかが未入力、またはフックレス（適合確認が必要なため） |
| 入力した上限以下 | フック付きで、リム・タイヤ両方の最大空気圧が入力済みで、推奨値がその低い方以下 |

- 「安全」とは判定・表示しない
- 警告が出ても推奨空気圧は自動では変わらない
- リム構造が不明で推奨値が 5.0 bar を超える場合は「フックレスリムの場合は目安を超えている」旨を表示
- フックレスの場合は、リムメーカーが適合を認めたチューブレス対応（TLR/TLE）タイヤのみ使えること（チューブを入れる場合も同じ）を常に表示。タイヤの種類が「クリンチャー」ならその旨も表示

### 5. ライト／ダークモード

- 画面右上のボタンで切り替え（ライト表示中は「🌙 ダーク」、ダーク表示中は「☀️ ライト」）
- 一度も切り替えていなければ、端末のダーク／ライト設定に合わせる

## 保存されるデータ

すべて端末のブラウザ内（localStorage）だけに保存され、外部には送信されません。共有した相手のデータと混ざることはありません。

| キー | 内容 |
|---|---|
| `ap-from` / `ap-to` | 最後に選んだ入力単位・変換後の単位 |
| `ap-slots` | 前輪・後輪の保存値（kPa） |
| `ap-rec` | 推奨空気圧の入力内容（体重・車体・幅・路面・タイヤの種類）と詳細設定（リム構造・リム／タイヤ最大空気圧・単位） |
| `ap-theme` | ライト／ダークの選択 |

注意：
- アプリを削除したり、ブラウザの Web サイトデータを消したりすると、保存値も消える
- iPhone では、Safari で開いた場合とホーム画面のアプリで開いた場合で保存場所が別

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・計算・保存をすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色 |
| `docs/verification.md` | 推奨空気圧の計算式とメーカー公開データの比較（検証表） |
| `sw.js` | オフライン用のキャッシュ（ネット優先、つながらなければキャッシュ） |
| `icons/air-180.png` | iPhone のホーム画面アイコン |
| `icons/air-192.png` / `icons/air-512.png` | Android 用アイコン |

## 更新・公開の手順

1. `index.html` などを修正する
2. `sw.js` の `CACHE` のバージョン番号を1つ上げる（例：`air-pressure-v6` → `v7`）
3. `main` ブランチに push すると、GitHub Pages が自動で公開（数分）
4. スマホではアプリを一度閉じて開き直すと新しい画面になる

公開が失敗した場合：Actions の「pages build and deployment」を確認。デプロイがタイムアウトしただけなら、再実行すれば通ることが多い。
